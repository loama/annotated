# Annotated Chrome side panel

## Install locally

1. Download and unzip `annotated-sidepanel.zip`.
2. Open `chrome://extensions` in Chrome.
3. Turn on Developer mode.
4. Choose **Load unpacked** and select the unzipped folder.
5. Pin Annotated, then click its toolbar action beside any article, YouTube video, or podcast.

The extension opens as a native Chrome side panel. It reads only the active page when the panel opens or when you press recapture. Selected text and media timing are passed directly into the annotation studio.
